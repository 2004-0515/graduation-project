# 第二章 相关技术

本章介绍系统开发过程中所采用的核心技术，包括后端开发框架、前端技术栈、数据持久化方案、系统安全机制以及开发辅助工具等方面的内容。

## 2.1 后端技术

### 2.1.1 Java语言

Java是一门成熟的面向对象编程语言，具有跨平台、安全性高、生态完善等特点。本系统采用Java作为后端开发语言，利用其长期支持版本提供的记录类型、模式匹配、密封类等现代特性，使代码更加简洁和类型安全。

### 2.1.2 Spring Boot框架

Spring Boot是Spring框架的最新主版本，专为简化Spring应用的初始搭建和开发过程而设计。该框架通过约定优于配置的理念和自动配置机制，使开发者能够快速构建生产级别的应用程序。Spring Boot集成了Web容器，提供了健康检查、指标监控等生产就绪特性，在本系统中负责整个后端架构的搭建，包括Web服务、数据访问、安全控制等核心功能模块的集成与管理。

### 2.1.3 Spring Data JPA

JPA是Java EE标准的对象关系映射规范，Spring Data JPA是Spring对JPA的封装和增强。该框架通过注解将Java实体类映射到数据库表，提供了统一的Repository抽象接口，支持通过方法命名规则自动生成查询语句，内置了分页和排序支持。本系统使用Spring Data JPA作为数据访问层框架，简化了数据库操作的实现。

### 2.1.4 Maven构建工具

Maven是Java生态中主流的项目管理和构建工具，采用项目对象模型来管理项目的构建、依赖和文档。本系统使用Maven统一管理第三方库的版本，确保了开发环境和生产环境的一致性。

## 2.2 前端技术

### 2.2.1 Vue框架

Vue.js是一套用于构建用户界面的渐进式JavaScript框架，以其易学易用、灵活高效的特点广受开发者欢迎。本系统采用Vue 3版本，该版本引入了Composition API，提供了更灵活的代码组织方式，并在性能和类型支持方面有显著提升。

### 2.2.2 TypeScript语言

TypeScript是JavaScript的超集，为JavaScript添加了静态类型系统。在大型前端项目中使用TypeScript能够在编译时发现类型错误，提供精确的代码补全和重构支持，提高了代码的可维护性。本系统前端全面采用TypeScript开发，定义了完整的类型系统，确保了前后端数据结构的一致性。

### 2.2.3 Element Plus组件库

Element Plus是基于Vue 3的桌面端组件库，提供了丰富的UI组件和完善的设计规范。该组件库包含60多个高质量组件，支持主题定制和国际化，采用响应式设计能够自适应不同屏幕尺寸。本系统使用Element Plus构建用户界面，大幅提升了开发效率和用户体验。

### 2.2.4 Pinia状态管理

Pinia是Vue官方推荐的新一代状态管理库，提供了简洁的API和完整的TypeScript类型推导支持。本系统使用Pinia管理用户登录状态、购物车数据等全局状态，实现了跨组件的数据共享和状态同步。

### 2.2.5 Vite构建工具

Vite是新一代前端构建工具，利用浏览器原生ES模块特性实现按需编译，提供了快速的开发服务器启动和模块热更新体验。本系统使用Vite作为前端开发和构建工具，显著提升了开发效率。

### 2.2.6 Axios HTTP客户端

Axios是基于Promise的HTTP客户端，提供了拦截器机制、请求取消、自动数据转换和统一错误处理等功能。本系统封装了Axios实例，配置了请求和响应拦截器，所有API调用都通过模块化的API文件进行，保证了代码的可维护性。

## 2.3 数据库技术

### 2.3.1 MySQL数据库

MySQL是世界上最流行的开源关系型数据库管理系统，以其高性能、高可靠性和易用性著称。本系统采用MySQL作为数据存储方案，利用其InnoDB存储引擎提供的ACID事务保证来确保数据一致性，通过多种索引类型提升查询性能。系统存储了用户、商品、订单、评价等核心业务数据，通过合理的表结构设计和索引优化，保证了系统的查询效率和数据完整性。

## 2.4 系统架构

### 2.4.1 前后端分离架构

本系统采用前后端分离的架构模式，前端和后端作为独立的应用部署和运行。这种架构实现了职责的清晰分离，前端专注于用户界面和交互体验，后端专注于业务逻辑和数据处理。前后端通过RESTful API进行通信，数据格式统一采用JSON，便于系统的扩展和维护。

### 2.4.2 RESTful API设计

REST是一种软件架构风格，强调资源的表述和状态转移。本系统遵循RESTful设计原则，采用资源导向的设计思路，使用HTTP方法的语义化特性，所有API返回统一的JSON格式，使用标准的HTTP状态码表示请求结果，确保了API的规范性和可理解性。

### 2.4.3 分层架构

后端采用经典的三层架构模式，包括Controller层、Service层和Repository层。Controller层负责接收HTTP请求并封装响应，Service层实现核心业务逻辑，Repository层封装数据库操作。这种分层设计遵循单一职责原则，降低了代码耦合度，提高了可测试性和可维护性。

## 2.5 安全技术

### 2.5.1 JWT认证机制

JWT是一种开放标准，用于在各方之间安全地传输信息。JWT由Header、Payload和Signature三部分组成，相比传统的Session认证具有无状态、跨域支持和移动端友好等优势。本系统使用JWT实现用户认证，用户登录成功后返回Token，后续请求通过Authorization请求头携带Token进行身份验证。

### 2.5.2 BCrypt密码加密

本系统使用BCrypt算法对用户密码进行加密存储。BCrypt是一种基于Blowfish密码的哈希函数，具有自适应性、自动加盐和单向性等特点，能够有效防止密码破解和彩虹表攻击，保障了用户账户的安全性。

### 2.5.3 基于角色的访问控制

本系统实现了基于角色的访问控制机制，将用户分为普通用户、卖家用户和管理员三种角色，不同角色拥有不同的操作权限。系统通过Spring Security的注解实现接口级别的权限控制，前端通过路由守卫检查用户权限，确保了系统的安全性。

## 2.6 单元测试

软件测试是保证代码质量的重要手段。后端测试使用JUnit 5和Mockito框架，JUnit 5提供了丰富的断言和测试生命周期管理功能，Mockito可以创建Mock对象隔离测试单元的依赖关系。前端测试使用Vitest和Vue Test Utils框架，Vitest是基于Vite的测试框架，Vue Test Utils提供了组件挂载和交互模拟功能。本系统实现了完善的单元测试体系，确保了代码的正确性和稳定性。

## 本章小结

本章系统地介绍了项目开发所采用的技术体系。在后端方面，采用Java语言和Spring Boot框架构建应用，使用Spring Data JPA进行数据持久化，Maven管理项目依赖。在前端方面，采用Vue框架和TypeScript语言开发，使用Element Plus组件库构建界面，Pinia管理应用状态，Vite作为构建工具，Axios处理HTTP通信。在数据存储方面，采用MySQL关系型数据库。在架构设计方面，遵循前后端分离模式和RESTful API规范，后端采用三层架构。在安全保障方面，采用JWT认证机制、BCrypt密码加密和基于角色的访问控制。在质量保障方面，使用JUnit和Vitest进行单元测试。这些技术的合理选择和应用，为系统的高性能、高可用性和易维护性提供了坚实的技术基础。
