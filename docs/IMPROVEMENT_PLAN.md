```
特色功能包括：理性消费助手、智能搜索优化、订单审核流程。
技术亮点：前后端分离、RESTful API、JWT认证、完整测试覆盖。"
```

**展示内容**：
- 打开项目README.md，快速介绍技术栈

- 说明数据库设计（18张表）

### 第二幕：普通用户购物流程（7分钟）⭐ 核心演示

**测试账号**: zhangsan / 123456

#### 2.1 首页浏览（30秒）
- 展示轮播图、热销商品、新品推荐
- 点击分类导航查看商品分类

#### 2.2 智能搜索（1分钟）⭐ 技术亮点
```
演示步骤：
1. 点击搜索框，展示搜索历史记录
2. 输入"手机"，展示搜索建议下拉框
3. 查看热门搜索词（Top 8）
4. 执行搜索，查看结果
```
**说明**: "搜索功能包含历史记录、热门关键词、实时建议三大优化"

#### 2.3 商品详情（1分钟）
```
演示步骤：
1. 点击商品进入详情页
2. 查看商品信息、价格、库存
3. 查看价格历史图表（如果有数据）
4. 查看商品评价（评分、评论、图片）
5. 点击"加入购物车"
```

#### 2.4 购物车操作（1分钟）
```
演示步骤：
1. 点击购物车图标
2. 修改商品数量（测试库存限制）
3. 选择/取消选择商品
4. 查看总价自动计算
5. 点击"去结算"
```

#### 2.5 下单流程（2分钟）
```
演示步骤：
1. 选择收货地址（或新增地址）
2. 选择优惠券（展示优惠金额计算）
3. 确认订单信息（原价、优惠、实付）
4. 提交订单
5. 模拟支付（选择微信/支付宝）
6. 支付成功，跳转订单详情
```
**说明**: "订单创建时会扣减库存，支付成功后标记优惠券已使用"

#### 2.6 订单管理（1分钟）
```
演示步骤：
1. 查看"我的订单"列表
2. 使用状态筛选（待付款/待发货/待收货等）
3. 点击订单查看详情
4. 确认收货
5. 评价商品（评分+文字+图片上传）
```

#### 2.7 理性消费功能（1.5分钟）⭐ 创新亮点
```
演示步骤：
1. 进入"理性消费"页面
2. 设置月度预算（如5000元）
3. 查看消费报告：
   - 本月消费金额
   - 预算使用百分比
   - 消费趋势图表
   - 分类消费统计
4. 查看心愿单（24小时冷静期）
5. 查看重复购买检测
```
**说明**: "理性消费助手帮助用户控制消费，避免冲动购物"
