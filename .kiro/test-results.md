## 问题详情

### 问题 1: 退出登录后购物车图标仍显示数量 ✅

**状态**: ✅ 已修复
**发现时间**: 2026-03-04
**严重程度**: 中等

**问题描述**: 
用户退出登录后，导航栏购物车图标仍然显示商品数量，给用户造成困惑。

**复现步骤**:
1. 登录用户账号
2. 添加商品到购物车（购物车图标显示数量）
3. 点击退出登录
4. 观察购物车图标仍显示数量（错误）

**根本原因**: 
`Navbar.vue` 的 `handleLogout()` 函数只调用了 `userStore.logout()`，没有清空购物车和通知的前端状态。

**解决方案**: 
在 `handleLogout()` 函数中添加状态清理：
```typescript
const handleLogout = async () => {
  await userStore.logout()
  // 清空购物车状态
  cartStore.items = []
  // 清空通知数量
  notificationStore.clearCount()
  ElMessage.success('已退出登录')
  router.push('/')
}
```

**修复文件**: `frontend/src/components/Navbar.vue`

**验证结果**: ✅ 通过
- 退出登录后购物车图标正确显示为 0
- 通知图标也正确清空

**详细文档**: `.kiro/test-issue-1-logout-cart.md`

### 问题 2: 登录后跳转到购物车页面 ✅

**状态**: ✅ 已修复
**发现时间**: 2026-03-04
**严重程度**: 中等

**问题描述**: 
用户从购物车页面退出登录后，再次登录时会自动跳转回购物车页面，而不是首页。这不符合电商网站的常见用户体验。

**复现步骤**:
1. 登录并访问购物车页面 `/cart`
2. 点击退出登录
3. 点击登录按钮
4. 输入用户名密码登录
5. 登录成功后跳转到 `/cart` 而不是 `/`（错误）

**根本原因**: 
1. 路由守卫在访问受保护页面时设置 `redirect` 参数: `/login?redirect=/cart`
2. 登录成功后使用 `redirect` 参数跳转
3. 退出登录后浏览器历史记录中仍保留 redirect 参数

**解决方案**: 
修改 `LoginView.vue` 的 `handleLogin()` 函数，移除 redirect 逻辑，登录后始终跳转到首页：
```typescript
// 修改前
const redirect = router.currentRoute.value.query.redirect as string
router.push(redirect || '/')

// 修改后
// 登录后始终跳转到首页，避免 redirect 参数导致的跳转问题
router.push('/')
```

**修复文件**: `frontend/src/views/LoginView.vue`
