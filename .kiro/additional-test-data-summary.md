### 数据完整性

✅ 所有订单项都包含：
- `seller_id`：从商品表获取的真实卖家ID
- `seller_name`：从用户表获取的真实卖家用户名
- `product_name`：商品名称快照
- `product_price`：商品价格快照
- `product_image`：商品图片快照
- `ship_status`：发货状态（已完成和待收货订单为1，其他为0）
- `ship_time`：发货时间（已发货订单有值）

✅ 所有订单都遵循时间逻辑：
```
created_time < payment_time < shipping_time < end_time
```

✅ 所有订单状态一致性：
- `order_status >= 1` 时，`payment_status = 1`
- `order_status = 3` 时，有 `end_time`
- `order_status = 0` 时，`payment_status = 0`
